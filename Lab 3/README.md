## 6. Program / Queries / Commands
The following are task-wise program examples for Assignment 3.

```javascript

const marks = 72;
if (marks >= 75) console.log("Grade A");
else if (marks >= 60) console.log("Grade B");

// Task 2
for (let i=1; i<=5; i++) console.log(i);

// Task 3
let total=0, n=1;
while (total <= 20) { total += n; n++; }
```
