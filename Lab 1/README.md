## 2. Aim
Run JavaScript in a browser and Node.js; use const, let and typeof.

## 3. Software / Tools Required
JavaScript, Node.js, Visual Studio Code and a web browser (for HTML/DOM experiments).

## 4. Theory
JavaScript makes web pages interactive and also runs with Node.js. console.log() prints messages. const declares a value that cannot be reassigned, let declares a reassignable variable, and typeof reports a value's type.

## 5. Algorithm / Procedure

## 6. Program / Queries / Commands
The following are task-wise program examples for Assignment 1.

